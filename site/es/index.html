Lo que un desarrollador abre todos los días, en un solo panel.

DevPanel es una app de Windows gratuita y de código abierto que reúne tus repositorios de GitHub, tus proyectos locales, herramientas de desarrollo y Claude Code, y se abre con tu rostro o con un código de 4 dígitos.

Descargar para Windows Código en GitHub

Windows 10 y 11 · Español e inglés · Licencia MIT

Qué hace

GitHub de un vistazo

Repositorios, commits, ejecuciones de Actions y pull requests, con un aviso cuando un build falla.

Proyectos locales

Rama y cambios, diagnóstico del proyecto con arreglos de un clic y scripts de npm en una terminal integrada.

Herramientas sin internet

JSON, Base64, JWT, hashes, UUID, fechas y regex en tu equipo. Ningún token pegado en una web.

Claude Code

Habla con Claude Code sobre un proyecto, con su diagnóstico como contexto.

Acceso con tu rostro

Desbloquea con tu rostro y un giro de cabeza al azar que frena las fotos, o con tu código de 4 dígitos.

Actualizaciones automáticas

Busca versiones nuevas al abrir y cada 15 minutos, y te muestra qué cambió después de cada actualización.

Pantallas

Descargar

  1. Descarga DevPanel-Installer.exe desde la versión del instalador en GitHub.
  2. Ábrelo. Descarga la última versión y comprueba su suma SHA-256 antes de instalar.
  3. Vincula tu usuario de GitHub, crea tu código de 4 dígitos y, si quieres, registra tu rostro.

Privacidad y seguridad

Tus datos se quedan en tu equipo

La configuración, tu código, la huella de tu rostro y tu token de GitHub se guardan en tu PC, cifrados por Windows.

Sin fotos

El acceso facial guarda una huella numérica de tu rostro, nunca fotos ni video.

Abierto y revisado

El código es público. Cada cambio pasa pruebas, CodeQL y escaneo de secretos en GitHub Actions.

Everything a developer opens every day, in one panel.

DevPanel is a free, open-source Windows app that brings your GitHub repositories, your local projects, developer tools and Claude Code together, and opens with your face or a 4-digit code.

Download for Windows Source code on GitHub

Windows 10 and 11 · Spanish and English · MIT license

What it does

GitHub at a glance

Repositories, commits, Actions runs and pull requests, with a desktop alert when a build fails.

Local projects

Branch and changes, a project diagnosis with one-click fixes, and npm scripts in a built-in terminal.

Developer tools, offline

JSON, Base64, JWT, hashes, UUIDs, dates and regex, all on your machine. No token pasted into a website.

Claude Code

Talk to Claude Code about a project, with the project's diagnosis as context.

Face sign-in

Unlock with your face and a random head turn that stops photos, or with your 4-digit code.

Automatic updates

Checks for new versions on start and every 15 minutes, and shows what changed after each update.

Download

  1. Download DevPanel-Installer.exe from the installer release on GitHub.
  2. Run it. It downloads the latest version and checks its SHA-256 checksum before installing.
  3. Link your GitHub username, create your 4-digit code and, if you want, enroll your face.
Download for Windows All releases and release notes

Code signing. Free code signing provided by SignPath.io, certificate by SignPath Foundation. Until signed builds are published, Windows SmartScreen may show "Unknown publisher": download DevPanel only from this page or its GitHub releases.

Privacy and security

Your data stays on your PC

Settings, your code, your face fingerprint and your GitHub token are stored locally, encrypted by Windows.

No photos

Face sign-in keeps a numeric fingerprint of your face, never pictures or video.

Open and reviewed

The code is public. Every change runs tests, CodeQL and secret scanning on GitHub Actions.
